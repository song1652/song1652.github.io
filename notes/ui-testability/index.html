UI 식별자 개선으로
회귀 자동화의 안정성을 높인 경험

MORA RTM/REHAB의 Selenium WebDriver 회귀 자동화를 구성하며, 제품 업데이트에 따라 XPath가 바뀌는 문제를 발견했습니다. 개발팀과 고유 ID를 적용해 요소 탐색 기준을 개선하고, 업데이트 후에도 자동화가 정상 동작하는 것을 확인했습니다.

MORA RTM / REHAB개발팀 협업적용 후 검증
CONTEXT

반복 회귀 검증을 자동화하던 과정

기존 제품과 화이트라벨 버전의 공통 기능을 반복해서 확인하기 위해 Selenium WebDriver 기반 회귀 자동화를 구성했습니다. 화면의 요소를 찾아 클릭하고 값을 읽는 과정에서 XPath를 활용했습니다.

PROBLEM

기능은 같아도, 요소를 찾는 경로가 달라졌습니다

제품이 업데이트되면서 XPath 값이 바뀌어 기존 자동화 코드의 요소 탐색에 문제가 발생했습니다. 기능의 정상 동작과 별개로, 화면 요소를 찾는 기준이 바뀌면 테스트가 영향을 받는 상황이었습니다.

문제는 XPath라는 방식 자체가 아니라, 업데이트와 함께 달라지는 경로를 테스트 대상의 식별 기준으로 사용하고 있다는 점이었습니다. 반복 실행할 회귀 테스트에는 같은 요소를 지속적으로 찾을 수 있는 기준이 필요했습니다.

회귀 테스트에서 구분해야 할 두 가지

제품 기능의 실패
기대했던 동작이나 결과가 실제 제품에서 충족되지 않는 경우

요소 탐색의 실패
대상을 찾는 경로가 바뀌어 테스트가 필요한 동작까지 진행하지 못하는 경우

CONTRIBUTION

개발팀과 자동화의 선행 조건을 맞췄습니다

XPath 변경으로 발생한 문제를 바탕으로, 자동화 대상 요소에 고유 ID를 넣어 달라고 개발팀에 요청했습니다. 변경된 경로에 맞춰 테스트를 수정하는 대응에 더해, 제품에서 대상을 식별하는 기준도 함께 개선하고자 했습니다.

요청의 목적은 ID를 추가하는 것 자체가 아니라, 업데이트 이후에도 자동화가 같은 요소를 찾도록 만드는 것이었습니다. QA 관점에서 발견한 테스트 가능성(Testability)의 문제를 개발팀이 반영할 수 있는 개선 요청으로 연결했습니다.

제가 맡은 역할
  • Selenium WebDriver 자동화에서 XPath 변경에 따른 요소 탐색 문제 확인
  • 개발팀에 자동화 대상 요소의 고유 ID 적용 요청
  • ID 반영 이후 제품 업데이트에서 자동화 동작 재확인
DESIGN PRINCIPLES

이 경험에서 정리한 UI 식별자의 기준

개발팀에 요청하고 실제 반영을 확인하는 과정을 통해, 자동화가 의존할 식별자는 다음 기준으로 살펴봐야 한다고 정리했습니다.

UNIQUE

대상을 고유하게 구분

같은 화면에서 자동화가 어떤 요소를 찾는지 명확해야 합니다.

STABLE

업데이트에도 의미 유지

화면의 배치나 경로가 달라져도 같은 대상을 식별할 수 있어야 합니다.

RELEVANT

실제 검증 동작과 연결

클릭·입력·값 확인 등 테스트가 사용하는 대상을 기준으로 살펴봅니다.

VERIFIABLE

반영 후 다시 검증

식별자 적용 여부와 함께, 업데이트 이후 테스트의 실제 동작을 확인합니다.

RESULT

실제 적용과 업데이트 후 검증까지 이어졌습니다

개발팀에서 요청한 고유 ID를 실제 제품에 적용했습니다. 이후 제품을 업데이트해도 기존에 겪었던 XPath 변경에 따른 문제가 발생하지 않는 것을 확인했습니다.

확인한 결과고유 ID 적용 후, 업데이트에서도 자동화가 정상 동작하는 것을 확인했습니다.
QA PRINCIPLE

안정적인 자동화에는 제품의 테스트 가능성이 필요합니다

자동화 코드를 작성하는 과정에서, 제품이 테스트 대상을 안정적으로 식별할 수 있는 구조도 함께 필요하다는 점을 확인했습니다. 테스트가 실행된다는 사실과 업데이트 이후에도 믿고 반복할 수 있다는 것은 함께 살펴봐야 할 기준입니다.

QA는 제품에서 반복 검증을 어렵게 만드는 조건을 발견하고, 이를 개발팀과 논의할 수 있는 개선 요구사항으로 구체화할 수 있습니다. 이 사례에서는 고유 ID의 실제 반영과 후속 업데이트 검증까지 연결했습니다.

자동화의 안정성은 코드와 제품이 함께 만듭니다.
QA는 그 사이의 검증 기준을 연결합니다.
